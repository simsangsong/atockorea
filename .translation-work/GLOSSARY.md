## 5. Style Guide per Locale

### KO (Korean)
- 톤: 자연스러운 한국어 여행 콘텐츠 (트래블 매거진 / OTA 카피 톤). 존댓말 일관성.
- 영어 단어 직역 금지. "experience" → "경험" 보다는 "둘러보기" 같은 자연스러운 표현 검토.
- 시스템 용어 (loading, click here, user, submit 등) 그대로 음역 금지.
- 길이: EN 대비 0.7-1.1배가 자연스러움.

### JA (Japanese)
- 톤: 旅行記事 / OTA 사이트 톤. ですます체 통일.
- 한국 지명: 한자 + 가타카나 병기 첫 1회 (예: 漢拏山（ハルラサン）), 이후엔 한자만.
- 외래어는 카타카나 (例: シャトル、ピックアップ).
- 過剰なAI口調を避ける。「最高の体験を提供します」「皆様におすすめ」「自然と調和した」などは自然な日本語に置き換える。
- 길이: EN 대비 0.9-1.2배.

### ZH (Simplified Chinese — Mainland)
- 风格: 中国大陆OTA风格 (携程/马蜂窝). 简体字.
- 用词: 软件 (not 軟體), 网络 (not 網路), 出租车 (not 計程車), 视频 (not 影片).
- 韩国地名标准音译 (济州、釜山、首尔、汉拿山).
- 不要直译英文，避免AI腔 ("为您提供"、"打造"、"独特体验"过度使用).
- 길이: EN 대비 0.5-0.8배 (중국어는 짧음).

### ZH-TW (Traditional Chinese — Taiwan)
- 風格: 台灣繁體字, 台灣慣用詞.
- 用詞: 軟體 (not 软件), 網路 (not 网络), 計程車 (not 出租车), 影片 (not 视频), 韓國 (not 韩国).
- 旅遊雜誌風格.
- 길이: EN 대비 0.5-0.8배.

### ES (Spanish — neutral international)
- Tono: editorial de viajes. Español neutro (evitar regionalismos exclusivos).
- Acentuación correcta. Comillas españolas «» o ".
- Evitar tono de IA ("descubre lo mejor de", "experiencia única", "sumérgete en" en exceso).
- Mantener nombres propios coreanos en romanización oficial (Hallasan, no "Halla-san").
- 길이: EN 대비 1.0-1.3배.

## 6. STRUCTURAL RULES (CRITICAL — applies to ALL locales)

1. **Preserve EXACTLY**:
   - All JSON keys (untranslated)
   - All URLs (https://..., image paths)
   - All numbers (durations, prices, ratings, schema_version)
   - All booleans
   - All lowercase identifier strings (snake_case, kebab-case): `"small_group"`, `"jeju"`, `"unesco"` in `tags` arrays — these are filter IDs, not display labels
   - All ISO datetime strings, locale codes other than the `locale` field
   - `slug`, `product_id`, `document_kind`, `schema_version`, `priceSource`, `ogImage` paths, icon names ("camera", "mountain", etc.)
   - Times like "08:30", "≈18:00" — keep numbers, but unit suffixes can be localized

2. **Translate**:
   - All natural-language strings (titles, descriptions, headlines, taglines, paragraphs, captions, button labels)
   - User-facing labels in `badges`, `pills`, `subnavItems[].label`
   - Display values in arrays that are clearly user-facing

3. **Match EN structure 1:1**:
   - Same keys present in target as in EN
   - Same nesting
   - Same array length
   - Same array order
   - DO NOT add fields that EN doesn't have (e.g., do not add `seo.description` if EN has only `seo.metaDescription`)
   - DO NOT remove fields that EN has

4. **The `locale` field** must equal the target locale code (e.g., `"locale": "ko"`).

5. **NO HALLUCINATION**: If EN doesn't mention something, do not add it. Translate only what's in EN.

6. **NO AI TONE / NO SYSTEM TERMS**: Re-read your output as a native speaker. If it sounds machine-translated, rewrite.
