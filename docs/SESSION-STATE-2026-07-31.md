## 🔴 이번 라운드에서 배운 것 — 20~24

### 20. 🔴 게이트를 조용하게 만드는 방법이 두 가지 더 있다 (둘 다 이 세션이 저지를 뻔했다)

**① 주석 안의 중괄호.** P7.2 에서 `--tr-plan-shadow-{soft,card,button}` 이라고 **주석에** 적었다.
`skinContrast` 의 블록 파서는 `{`/`}` 로 쪼개므로 **주석 한 줄이 뒤 규칙 전부의 파싱을 어긋나게 했고**,
플래너 토큰이 통째로 사라져 게이트가 "팔레트를 재는 것"에서 **"아무것도 안 재는 것"** 이 됐다.
→ 브레이스 스캔 **전에** 주석 제거. 적대적 케이스 `/* { probe } */` 로 확인.

**② `var()` 별칭.** P7.8 에서 값을 한 번만 두려고 `--tr-plan-v-*` 로 별칭을 걸었더니,
게이트가 읽는 `--tr-surface` 가 **문자열 `var(--tr-plan-v-surface)`** 가 됐다. WCAG 계산은 **NaN**,
그리고 **이 테스트들은 NaN 을 건너뛴다.** → 리졸버에 역참조 + **미해결 `var()` 가 남으면 실패**하는 테스트.

**공통 교훈: 게이트를 조용하게 만드는 건 보통 코드가 아니라 그 옆의 것이다** — 산문, 별칭, 리팩터.

### 21. 🔴 "배경만 스킨"은 팔레트가 가질 수 없는 관계를 요구한다

§N-9 B안을 곧이곧대로 넣자 **sky/light 에서 `ink-3` on `canvas` = 3.31**.
**캔버스와 잉크는 한 쌍**이다 — 스킨은 저마다 *자기 배경에서* 읽히는 잉크를 고르므로,
한 화면의 잉크를 고정한 채 배경만 갈면 **두 값을 안전하게 만들던 유일한 관계**가 끊긴다.
→ 선을 **팔레트가 실제로 접히는 곳**에 그었다: **중립 계열은 통째로 스킨**, **플래너는 accent 정체성**.
20조합 전부 통과. **디자인 결정을 실측이 뒤집은 사례**이고, 뒤집힌 이유가 취향이 아니라 구조다.

### 22. 스크린샷이 코드 리뷰가 못 본 걸 잡는다 (또)

P7.6 첫 초안이 코스 카드에 **DB 키 첫 글자**로 만든 스와치 "U"·"M" 을 띄웠다 —
바로 아래 미리보기 줄은 **전혀 다른 세 곳**을 나열하는 채로. 클래스명·계산값으로는 안 보였다.
원인: 미리보기 줄은 `poiByKey` 로 **필터**하는데 내 스트립은 안 했다. **같은 데이터에 두 필터**.

### 23. 섹션을 옮기면 **방향을 가리키는 카피가 썩는다**

P7.4 가 「내 하루」를 위로 올리자 빈 상태 문구가 *"위에서 골라보세요"* 인데 피커가 아래가 됐다 —

지시어를 금지하는 게이트**를 넣었다.

**다섯 건 모두 테스트가 초록이었다.** 결함이 *호출자의 부재*라서 단위 테스트로는 안 잡힌다 —
그 테스트는 모듈을 직접 부르고 통과한다. → **소스 게이트 + 뮤테이션 테스트**.

### 26. "미착수"는 **일곱 번** 틀렸다
P0·P1·P2·P3·P4 에 이어 **X15 지오펜스**와 **N-f 레이어 분리**도 이미 돼 있었다.
이제 이건 우연이 아니라 **이 플랜의 성질**이다. 착수 전 5분 grep.

### 27. 🔴 기대 집합이 관대하면 **인증 실패를 통과로 센다**
K4 하니스가 `403` 을 정상 응답에 넣어 뒀는데, 실제로는 세션 대신 **토큰**을 보내고 있었다.
여러 줄이 PASS 로 보고되면서 증명한 건 *"인증 안 된 호출은 거부된다"* 뿐이었다.
(스태프 세션은 **투어가 아니라 예약 단위** — 방 3 세션은 방 7 에서 403.)

### 28. 🔴 `PASS ≠ 기능이 돌았다`
`tts`·`retranslate`·`reactions`·`read` 는 방에 메시지가 없으면 **조기 반환**(400/404)하는데
그게 기대 안에 있어 PASS 였다. **라우트는 답했지만 기능은 한 번도 실행되지 않았다.**
전제를 채우자 200 이 됐다. `captions`·`dining` 도 같은 이유.
→ **"핸들러가 답했다"와 "기능이 실행됐다"는 다른 주장이다.**

### 29. 🔴 입력 검증 오류가 **인가 계약을 가린다**
`captions` 를 빈 바디로 부르면 *누가 부르는지 확인하기 전에* 400 이 나온다.
제대로 된 입력을 넣자 403(가이드 전용)으로 바뀌었다 — 원장의 배우 선언 오류 **4건 중 마지막**은
이렇게 숨어 있었다.

### 30. 🔴 게이트를 조용하게 만드는 건 **코드가 아니라 그 옆의 것**
① **주석 안의 중괄호**가 브레이스 파서를 무너뜨려 "아무것도 안 재면서 초록"
② **`var()` 별칭**이 검사값을 NaN 으로 만들고 **NaN 은 건너뛴다**
둘 다 이 세션이 저지를 뻔했고 둘 다 자기 게이트가 잡았다. 스캔 전 주석 제거 + var 역참조로 수정.

### 31. **생성되는 문서를 손으로 고치지 말 것 — 그리고 문서만 고쳐도 게이트를 돌 것**

**게이트가 지키는 파일을 고치는 건 코드를 고치는 것이다.**
