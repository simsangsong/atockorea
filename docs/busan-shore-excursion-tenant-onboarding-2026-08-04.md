## 2. 이번에 끝낸 것

### 가격 — 센트까지 정확히
`parseListPriceUsd`가 **두 레지스트리 모두에서 `Math.round`로 달러 반올림**을 하고 있어
$58.79가 카드에서 $59로 찍혔다. 센트 반올림(`Math.round(n*100)/100`)으로 바꿨다.
정수 가격 상품은 영향 없다(49 → 49). `formatPrice`는 이미 소수부가 있을 때만 센트를 렌더한다.

**두 SLUG_OVERRIDES 맵이 어긋나 있던 것도 이 참에 맞췄다** — 소그룹이 린 84 / 무거운 79+취소선 85로
갈라져 있었다. 이제 3종 모두 두 맵에 동일하게 들어간다.

🔴 **취소선(정가)은 넣지 않았다.** 리스팅의 "30% off"는 채널 프로모 배지이고 원가가 화면에 없다.
없는 숫자를 지어내는 대신 정가를 비웠다. **정가를 표시하려면 사장님이 값을 주셔야 한다.**

### 픽업 — 두 터미널을 동등하게
우리 3종 모두 **이미 두 터미널을 갖고 있었다.** 문제는 서열이었다 — 영도를 "primary / 대형선용",
초량을 "alternate / secondary / 소형선·페리용"으로 적어 기본값이 있는 것처럼 읽혔다.
사장님 말씀대로 정해진 게 없으므로 **양쪽에 같은 문장**을 넣었다:
*"부산 기항 크루즈는 두 터미널 중 어느 쪽에도 접안합니다. 어느 터미널을 이용할지는 배가 접안하는
곳에 따라 정해지며 예약 후 확정됩니다."* (6로케일)

소그룹 상품은 픽업 아코디언이 **초량 하나만** 적어 놨었다(`preview` + `content[0]`). 두 자리 모두 교체.
「픽업」 글랜스 칩도 단일 터미널 값이었던 걸 "두 곳 중 접안지 — 예약 시 확정"으로 바꿨다.

## 4. 아직 안 맞춘 것 (남은 일)

이번 패스는 **가격·기간·픽업·정원**까지다. 스펙 대비 남은 항목:

1. **소그룹 코스가 리스팅과 다르다** — 자갈치·BIFF·국제시장을 한 스톱으로 묶어 놨고,
   송도/용두산이 *"시간 되면"* 조건부다. 리스팅은 9스톱을 각각 세운다.
   (조인 버스 상품 코스는 이미 사실상 일치 — 송도해변 1스톱 vs 구름산책로+스카이파크 2스톱 차이만)

3. **할증·취소·연령·크루즈 전용** 정책 문구 (₩10,000 / ₩50,000·시간 / ₩130,000 / 만 4세 / 비크루즈 거부)
4. **태종대 잔재** — 소그룹 `itineraryStops`에서 빠졌는데 `seo.metaDescription`·`routePhases`·FAQ 다수에 남아 있다
5. **프라이빗 내부 모순** — `hotel_pickup_available:false` + "호텔픽업 없음" ↔ SEO·DB·`mp.pickup_base`는
   "호텔/KTX 픽업 가능" / 최대인원 하드제약 7 ↔ 요금 티어 13 ↔ 차량설명 "밴 8–10명"
