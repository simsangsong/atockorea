## 3. 진짜 문제 — 발견 6가지

### 🔴 F1. 경쟁사가 이기는 가격대에 우리는 **상품이 없다**
경쟁사 주력은 **$58.79 ~ $68.95**. 그 구간에서 크루즈 손님이 Klook에서 우리를 만나면 보는 건 **$84** 하나다.
**22~43% 비싸고, 더 싼 대안이 화면에 없다.**
$49 버스투어가 정확히 그 아래 칸을 먹는 상품인데 **꺼져 있다.**

### 🔴 F2. 꺼둔 $49 버스투어가 **문서상 경쟁사보다 나은 상품이다**
- 스톱 **11개 vs 9개** — 송도해변·다이아몬드타워가 더 있다
- **전 스톱 시각 표기**(08:30 픽업 ~ 19:15 귀항) vs 경쟁사는 시각 없는 나열
- **"19:30까지 귀항 보장"** 명문 + `catalog_card.badges`에 `"Return guaranteed"`
- 주 코스 입장료 전부 무료 = 경쟁사의 "입장료 포함"과 **실질 동일**
- 가격 **$49 < $58.79** (경쟁사 30%할인가 기준으로도 우리가 싸다)

차단 사유는 상품 결함이 아니라 **2026-06-29 Klook 12 SKU 축소** — 이 경쟁사를 보기 전의 결정이다.
🔴 **이 트랙의 단일 최대 레버.** 되살릴지는 사장님 결정.

### 🔴 F3. 판매중인 크루즈 주력 SKU의 **가격이 네 개다**
| 출처 | 값 |
|---|---|
| `catalogRegistrationBuilder.ts:46` (린 — 소비자 카드가 읽는 쪽) | **84** |
| `staticTourProductRegistry.ts:553` (무거운 — 상세페이지·어드민) | **79** + 취소선 **85** |
| 상품 JSON `price.amountLabel` | **84** |
| 같은 JSON FAQ 본문 (`q-vs-private`) | **"$58.50 per person"** |
| DB insert 원본 파일 | **58.50** |

경쟁사는 **"US$68.95 · 30% off"** 한 줄로 끝난다. 우리는 어느 화면을 여느냐에 따라 가격이 다르다.
두 레지스트리가 "sync 유지" 주석을 달고도 어긋나 있고, 부산 외 슬러그도 함께 벌어져 있다
(제주 그랜드 93 vs 79, 인천 프라이빗 424 vs 419 등).

### 🟡 F4. 같은 사실을 우리가 **더 못 팔고 있다**
- 경쟁사: **"Admission to attractions ✓"** (초록 체크 첫 줄)
- 우리: "UN·용두산·감천·자갈치는 **원래 무료입니다**"
→ 사실은 똑같은데, 우리 문장은 *"줄 게 없다"*로 읽힌다.

- 경쟁사: 송도 구름산책로 / 송도 스카이파크를 **각각 이름 붙인 스톱 2개**로 세움
- 우리 소그룹: **"시간 되면 송도해변 또는 용두산공원"** — 스톱 제목 자체에 유보를 넣었다
→ 경쟁사도 하단 주석에 "혼잡·날씨로 스킵될 수 있음"을 달아 같은 리스크를 헤지한다.
  **차이는 리스크가 아니라 어디에 적느냐다.**

### 🟡 F5. 리턴 보장 문구가 **팔리는 상품에서만 약하다**
경쟁사는 전 리스팅 최상단이 **"100% Guaranteed On-Time Port Return"**.
우리는 — 버스(차단): "guaranteed" / 프라이빗: "guaranteed" / **소그룹(주력, 판매중): "planned"**.
가장 정직한 표현이 하필 **유일하게 파는 크루즈 조인 상품**에 붙어 있다.

### 🟢 F6. 우리가 이미 이기고 있는데 **말을 안 하는 것 2가지**
1. **터미널 정확도.** 경쟁사는 「부산항국제여객터미널 2」(초량) **하나만** 적는다.
   우리는 **영도 크루즈터미널(대형선)** vs **초량 국제여객터미널(중소형·페리)**을 구분하고 좌표까지 갖고 있다
   (35.0747/129.0884 · 35.1149/129.0455). 부산 기항 대형 크루즈는 대체로 **영도**다 →
   경쟁사 리스팅은 대형선 승객에게 **틀린 집합장소**일 수 있다. 이건 진짜 차별점이다.
   ⚠ 단, 우리 소그룹 상품 내부가 자기모순이다: `pickup_dropoff`는 두 터미널, `practicalAccordionItems.pickup`은
   **초량 하나만** 적어 놨다.
2. **프라이빗 가격.** 경쟁사 VIP $456.99 — 게다가 **입장료 전부 제외**.
   우리 $364/차량, 실제 8시간 티어는 **1–6인 $230 / 7–9인 $264 / 10–13인 $331**.
   **20~50% 싸다.** 그런데 헤드라인 $364는 어느 티어 값과도 안 맞는다.

## 4. 두 줄 요약

**경쟁사는 $58.79 / $68.95 / $456.99 세 칸을 하나의 약속(100% 귀항 보장 + 입장료 포함 + 터미널 픽업)으로 깔끔하게 채웠다.**
**우리는 그 아래·위 두 칸을 이길 상품($49 버스, $364 프라이빗)을 이미 갖고 있으면서, 하나는 꺼놨고 하나는 안 자랑하고, 정작 파는 중간 칸은 가격이 네 개다.**

## 6. 부수 발견 (이번 조사 중 나온 것 — 별도 티켓감)

1. `busan-small-group-…-cruise-passengers` **정원이 3개 값**: 레지스트리 8 / 본문 "≈10" / 버스투어 비교 FAQ "≈12"
2. 같은 상품 `mp.lunch_included_fit: 1` ↔ 본문 **"점심 불포함"**
3. 같은 상품 **태종대가 코스에서 빠졌는데** `seo.metaDescription`·`routePhases`·FAQ 다수에 아직 남아 있다
4. `busan-private-car-charter-cruise-shore` — `hotel_pickup_available: false` + "호텔픽업 없음" ↔
   SEO·DB·`mp.pickup_base`는 **"호텔/KTX 픽업 가능"**이라고 광고
5. 같은 상품 최대 인원 **하드제약 7명** ↔ 요금 티어 **13명** ↔ 차량 설명 **"밴 8–10명"**
6. `busan-plum-…` / `busan-spring-…` 는 `amountLabel:""` → `listPriceUsd` **0**.
   지금은 차단 상태라 무해하지만 **푸는 순간 $0 카드**가 된다
7. `busan-cruise-shore-excursion-bus-tour` 는 소비자 차단인데 번들 내부 `matching_profile.is_active`는 아직 **true**
