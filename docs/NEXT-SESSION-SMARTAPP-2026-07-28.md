### 🔴 이 세션에서 실제로 시간을 태운 함정 5가지

1. **워크트리 dev 서버는 HMR이 안 먹는다.** 컴포넌트/CSS를 고치면 **반드시 재시작**해야 한다.
   재시작 안 하고 "before/after가 똑같다"는 결론을 두 번 냈다. 확신이 안 서면
   브라우저에서 `getComputedStyle` 로 **바뀐 클래스가 실제로 적용됐는지 먼저 찍어라**.
2. **shell 인용이 한글·정규식·백틱에서 깨진다.** `node -e "..."` 로 파일을 고치려 하지 말고
   **스크래치패드에 `.js` 파일을 써서 `node file.js` 로 실행**하라. 이 세션에서 4번 깨졌다.
3. **MCP 브라우저 펜은 숨은 탭을 합성하지 못한다** → 스크린샷이 안 나온다.
   **렌더 검증은 Playwright 헤드리스만** 쓴다(`scripts/qa-*-walk.mjs` 패턴).
4. **Next dev 오버레이(`<nextjs-portal>`)가 클릭을 먹는다.** Playwright에서
   `ctx.addInitScript` 로 `nextjs-portal{display:none}` 를 주입한다
   (`addStyleTag` 는 문서 하나에만 붙어서 네비게이션하면 죽는다).
5. **CDP 네트워크 스로틀은 localhost(루프백)에 안 걸린다.** 속도 측정은 CPU 스로틀만
   유효하거나, 프로덕션 도메인을 상대로 재야 한다.

🔴 **2026-07-29에 두 줄이 바뀐 이유 — 둘 다 실제로 물렸다.**

**① `npm run build`의 종료 코드를 봐라. 출력이 아니라.**

## §8 이 트랙에서 반복해서 나온 결함 유형 (다음 사람이 같은 걸 또 하지 않도록)

1. **"안 채운 인자"** — prop을 정의해놓고 안 넘긴다. `currentIndex`가 리치 카드에 안 갔고,
   `guest_submitted`가 CHECK에 없었고, 운영센터 전화 env가 세 곳 다 비어 있었다.
   → 도구: `scripts/qa-unfilled-props.mjs`
2. **레포에 있다 ≠ 적용됐다** — 마이그레이션 파일이 있어도 라이브에 안 걸려 있을 수 있다.
   **객체 존재로 검증**하라(파일명 매칭은 스크리닝일 뿐).
3. **같은 목록의 두 번째 사본은 반드시 어긋난다** — 로케일 맵을 손으로 베끼지 말고
   기존 것에서 **파생**시켜라(`NOW_LABEL` 이 그 패턴).
4. **문서가 코드보다 오래 산다** — 티켓을 닫을 때 **본문과 실행 로그를 같이** 고쳐야 한다.
   이 실수를 두 라운드 연속 했다. → `X19`(로그를 표에서 생성)
5. **추론을 측정처럼 쓰지 말 것** — "700KB가 셸"이라고 적었다가 실측에서 423KB로 반증됐다.
   숫자를 쓸 거면 **잰 것인지 계산한 것인지 문장에 표시**하라.
