## §B 완성형 길안내 영상 — 설계

### B-1 이 영상의 일은 두 가지다

**① 길을 외우게 한다** (wayfinding): 보고 나면 "주차장→상가→일주문→계단→전망대→다리→
대웅전→관음상→대나무길" 순서가 머리에 남아야 한다.
**② 가고 싶게 한다** (anticipation): 어디서 멈추고 어디서 폰을 들지 기대를 심는다.

시청 맥락: 투어 전날 밤/이동 차량(2–4분 집중 시청, 소리 있어도 없어도 됨) · 현장
프리타임(스톱 단위 점프 — 챕터가 곧 UI) · 유튜브/OTA(마케팅 표면 — 훅이 지배).
**무내레이션 유지가 설계 결정이다**: 소재가 무음 1인칭 보행이고, Kraig가 이 포맷의 시장
검증이며, 내레이션은 로케일 비용을 ×10 하고, 음성 해설은 이미 앱(도착 해설 TTS)의 일이다.

### B-2 정보 6층 모델 — 완성형이 답하는 여섯 질문

| 층 | 질문 | 전달 수단 |
|---|---|---|
| L1 약속 | 전체가 뭐냐 | 오프닝 클레임 타이틀 + 루트 약속 카드("8 stops · a 10-minute walk") |
| L2 방향 | 어디서 꺾냐 | 교차로 감속 1.5x(기존 확정 문법 — 화살표 아님) |
| L3 정체 | 지금 보는 게 뭐냐 | 스톱 라벨(번호+이름) |
| L4 이유 | 왜 봐야 하냐 | 스톱당 클레임 1줄(캡션) |
| L5 사진 | 어디서 찍냐 | 폴라로이드 리추얼(기존) + PHOTO SPOT 배지 |
| L6 비용 | 얼마나 걷냐 | 트랜짓 팩트("≈1½ min walk") — **원테이크의 고유 자산: 소스 타임코드가 곧 실측 보행시간**이라 발명이 아니라 측정이다 |

### B-3 구조 — 시간 축 스켈레톤

```
0:00–0:10  콜드 오픈: 머니샷 3컷 몽타주(각 ~2.8s, 디졸브), 컷1 위로 클레임 타이틀
0:10–0:16  루트 약속 카드: "8 stops · a 10-minute walk · ends where it starts"
0:16–      걷기 본편: 기존 v5 비트 시트 그대로 + 스톱 리추얼 텍스트만 얹는다
           스톱 리추얼 = 접근 감속(기존) → 라벨 in → 응시(클로즈업/1x)
                        → [사진: 폴라로이드+배지] → 라벨 out → 가속 + 트랜짓 칩
끝-8s      리캡: 폴라로이드 월(그 회차의 프린트 4–6장 배열) + 현판 북엔드 + © AtoC Korea
```

콜드 오픈은 Kraig 실측(오프닝=전체 하이라이트 몽타주)의 축소판이고, 유일하게 연대기를
깨는 구간이다. 소스가 다른 클립 3개를 잇는 것이므로 기존 규칙(클립 조인=0.8s 디졸브)을
그대로 따르며, 연속성 게이트는 인접 비트만 보므로 뒤에서 같은 클립을 다시 쓰는 것과
충돌하지 않는다(현판 엔딩과 같은 원리).

이 존 계약이 §G의 로케일 이원화를 성립시킨다: 마스터는 영어 웨이파인딩 층(고유명사+

`match_pois.content_locales` 10로케일 클레임을 얹는다. 충돌 좌표가 구조적으로 없다.
특정 로케일 풀번(외부 배포용)은 같은 텍스트 엔진에 `--locale`을 실구현해서 뽑는다
(비트 캐시 덕에 텍스트 얹는 비트만 재렌더).

수치 규격(레퍼런스 관례 + 가독 규칙, §D-W7 실측으로 보정):
글자는 흰색, 배경 휘도를 `pathLuma()`로 실측해 어두운 스크림을 **필요할 때만** 깐다

— 이미 사장님 앞을 통과한 아이덴티티를 확장하는 것이지 새 디자인이 아니다.
크기 ≥38px@1080p · 세이프 에어리어 5% · 표시시간 ≥ max(2.2s, 글자수/15초).

### B-7 세로본 v2 — 선별 규칙이 문제지 예산이 문제가 아니다

54/90s의 원인은 "1x와 정지만 선별"이라는 규칙. 개정:
**세그먼트 1 = 그 회차 최고 머니 비트**(파노라마 폴라로이드)로 시작 — 연대기 아님, 훅이
지배한다. 이후 연대기 복원, 1.2x 하이라이트 클립(다리·대나무길·오션뷰)을 6s 상한으로
채워 **예산의 80% 이상**을 쓴다. 마스터에서 리프트하는 원칙(그레이드·페이싱 드리프트
불가)과 화살표 배제는 불변.

### B-8 배포 산출물 — 렌더의 공짜 부산물 3종

build.mjs는 비트별 출력 오프셋을 이미 계산한다. 거기서:
1. **`<slug>.chapters.txt`** — 유튜브 설명란용 `0:00 이름` 줄들. 챕터 = 인트로 + 스톱들 +
   피날레(Kraig 패턴). 스펙에 `chapter: "이름"`을 스톱 시작 비트에 표기(관광지당 ~10줄).
2. **`<slug>.cues.json`** — 앱 오버레이 트랙: `{beat, kind, t0, t1, poiKey, textKey}`.
   Z4 클레임을 손님 로케일로 얹는 데 필요한 전부. `poi_videos` 검수 게이트와 연결.
3. **`<slug>-poster.jpg`** — 고정 템플릿 포스터(서재로36 교훈 2: 경직된 템플릿이 다양성을
   이긴다): 머니 프레임 풀블리드 + 세리프 클레임 + AtoC 네이비 칩. 1280×720 + 2000×1125.
   프레임은 스펙 `poster: {src, at}`로 지정하고 **풀해상도 재추출로 확정**(K-2 규칙).

## §D 스킬 완성 WBS

순서는 의존성이다: W0이 W2·W3의 문안을 확정하고, W1은 독립이라 먼저 가도 된다.
작업 브랜치는 기존 `claude/yonggungsa-video-edit-c14007` 워크트리(렌더 캐시·소스 존재).

### W0 — 사장님 결정 게이트 (목업 동반, 코드 최소)
`--only` 재렌더로 **목업 프레임 4장**을 만들어 보여드린다: ①클레임 타이틀 ②스톱 라벨+
트랜짓 칩 ③약속 카드 ④리캡 월. 받을 결정:
1. 와이드 텍스트 ON + Z4 예약 존 (B-4) — 이 문서의 권고안
2. 제목 register 전환 (B-5 표)
3. 포스터 템플릿 1안 확정 (이후 경직 운영)
4. 러닝타임 밴드 3:00–4:30 확인
5. (보류 재확인) 내레이션 없음 유지

### W1 — 모션 컷 (독립, 즉시 착수 가능)
`motioncut.mjs`: 같은 소스의 클립↔클립 경계마다 `panScore()`를 ±1.5s/0.2s 스텝으로
훑어 팬 극대점으로 경계를 스냅(양쪽 비트를 함께 이동 — 연속성 유지). freeze 인접 경계는
제외(프레임 일치 게이트가 우선). autoarrow처럼 스펙에 다시 써 넣는 방식.
게이트: 스냅 안 된 경계는 `nosnap` 사유 표기 강제.

### W2 — 텍스트 엔진 (이번 설계의 본체)
- `labels.mjs`: 스톱 라벨·트랜짓 칩·배지·타이틀·약속·리캡을 알파 PNG 시퀀스로 렌더
  (세로본 scene.mjs의 타이포 토큰 재사용; 렌더 경로는 overlay.mjs의 sharp 경로 우선,
  librsvg 폰트 폴백이 다르면 Playwright 경로로 — **렌더된 텍스트 bbox를 측정해 기대치와
  대조하는 게이트**로 폰트 침묵 교체를 잡는다)
- 스펙 필드: `label`, `transit: {seconds}`(수치는 in/out 델타에서 **자동 계산만** — 자유
  숫자 입력 불가), `chapter`, `poster`
- 게이트 신설 2종: **가독성**(§E-1) · **사실 검증**(§E-3)

### W3 — 구조 비트 (콜드 오픈 · 약속 · 리캡)
B-9 델타를 스펙에 반영. 리캡 월은 이미 렌더된 폴라로이드 PNG 재사용(신규 렌더 없음).
