## §D 화살표 문법 — 불변 규칙 (프로토타입 검증 완료)

> 지난 시도의 실패: **왼쪽에서 오른쪽으로 둥글게 휘는 곡선 화살표**. 의미가 없고
> 실제 길과 무관했다. 원인은 "경로"가 아니라 "장식"으로 그렸기 때문.

### D-1 불변 규칙
1. **모든 구간은 직선.** 베지어·스플라인 금지. 웨이포인트 사이는 무조건 직선 세그먼트.
2. **회전은 실제 꺾이는 지점에 날카로운 코너 1개.** 코너 라운딩 금지. 좌회전은 코너에서 정확히 왼쪽.
3. **계단은 수직 하강/상승으로 그리지 않는다.** 지그재그 폴리라인도 금지(엉킨다 — 실증됨).
   → **개별 셰브런 플레이트를 계단마다 하나씩**, 원근에 따라 간격이 압축되게 배치.
4. **폭은 원근에 따라 테이퍼**(가까울수록 넓게). 균일 폭 스트로크는 "떠 있는" 느낌을 준다.
5. **경로는 실제 보행면 위**에 놓는다. 하늘·벽·사람 머리 위를 지나면 안 된다.
6. **점진적 드로잉**(0.8–1.2s, ease-out) + 화살촉이 선단을 탄다.

### D-2 3종 문법 (`arrows[].mode`)

| `ribbon` | 직진 | 테이퍼 리본 + 셰브런 + 화살촉 |
| `ribbon` (코너 웨이포인트) | 좌/우회전 | 직선 → **날카로운 코너** → 직선 |
| `steps` | 계단 승강 | 분리된 셰브런 플레이트 N개, 원근 압축 |

## §F 파이프라인 아키텍처 (재사용의 핵심)

```
docs/video-specs/<poi-slug>.json      ← 관광지마다 이것 하나만 새로 쓴다
scripts/video-guide/
  build.mjs        오케스트레이터: spec → 비트별 ffmpeg 작업 → concat
  overlay/
    geometry.mjs   리본/플레이트/셰브런 기하  ✅ 프로토타입 완료
```

→ 6. **concat** (전 비트 코덱·fps·해상도 정규화)

### F-2 그래픽 렌더링
`sharp`(librsvg)로 SVG → 알파 PNG 시퀀스. **Playwright 불필요** — 결정론적이고 훨씬 빠르다.

## §K 실행 기록 — 다음 사람이 같은 걸 또 겪지 않도록

### K-1 🔴 계단 화살표는 지그재그 폴리라인으로 그리면 엉킨다
1차 구현은 계단을 "트레드-라이저" 지그재그 경로로 만들었다. 결과는 플레이트들이
서로 다른 방향을 보며 충돌하는 뭉치. **화면상 계단은 옆으로 지그재그하지 않는다** —
멀어지는 계단은 트레드도 라이저도 전부 화면 위쪽으로만 투영된다.
정답은 **직선 경로 + 분리된 플레이트 + 원근 간격 압축**(`perspective: 0.86`).
플레이트 깊이는 자기 구간 길이에 비례시켜야 멀어질 때 겹치지 않는다.

### K-2 🔴 `-ss` 시크 프레임 ≠ 컨택트시트의 그 프레임
컨택트시트는 `fps=1/5` 필터로 뽑고, 확인은 `-ss`로 뽑는다. **HEVC에서 두 결과가 다를 수 있다.**
"시트에서 봤으니 85초에 현판이 있다"가 틀렸고(→86초), 관음상은 202→205→**209**로 세 번 빗나갔다.
**시트로 고른 시각은 후보일 뿐이다. 풀 프레임으로 다시 뽑아 확인하고 스펙에 박아라.**

### K-3 🔴 좌표는 렌더해봐야 안다
그리드 눈금(240×270px)을 얹어 읽은 좌표도 **6곳 중 4곳이 빗나갔다.**
유일하게 믿을 수 있는 검증은 **합성해서 눈으로 보는 것**. 그래서 워크플로우가
`--only`+캐시로 짜여 있다 — 한 비트만 다시 굽는 게 몇 초면 된다.

### K-4 확신 없는 화살표는 넣지 않는다
전망대 좌회전(beat 15)은 프레임 판독이 불확실해 **v1에서 화살표를 뺐다.**
방향을 모르면서 넣는 화살표가 정확히 지난번 실패의 원인이다.

### K-5 환경
- 🔴 **이 워크트리에는 `node_modules`가 없다.** `sharp`는 `createRequire`로
  `atockorea-ops-next`에서 참조한다. **정션 링크 금지**(재귀 삭제가 링크를 타고 나간다).
- 🔴 **ffmpeg 필터 문자열에 `C:` 경로를 넣으면 파서가 콜론에서 깨진다.**
  `Push-Location` 후 상대경로를 쓰거나, Node에서 `spawnSync` 배열 인자로 넘겨라(권장).
- Windows ffmpeg 빌드는 `-pattern_type glob` 미지원 → 번호 시퀀스로 복사해서 `%02d`.

### K-6 남은 것
1. **음악 베드** — `spec.audio.bed`에 파일 경로. 없으면 현장음만(하이패스+라우드니스 정규화).
   상업 이용 가능 음원 필요.
2. **전망대 좌회전 화살표**(beat 15) — 프레임 재판독
3. **로케일 카드** — 마스터에는 굽지 않는다(§G 결정). 앱 오버레이용 큐 트랙 필요.
   원고는 새로 쓸 필요 없음: `match_pois.content_locales`에 `haedong_yonggungsa`가
