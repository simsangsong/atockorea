## §1 v1이 조잡했던 이유 — 실측 진단

### 1-1 🔴 화살표가 실제 걸어간 방향과 다르다 (근본 원인)

v1은 화살표 좌표를 **내가 프레임을 보고 눈으로 찍었다.** 그래서 틀렸다.
걷는 사람의 영상에는 정답이 이미 들어 있다 — **확장 초점(FOE)**. 앞으로 걸으면 화면의
모든 것이 한 점에서 바깥으로 흘러나오고, 그 점이 곧 진행 방향이다.

측정기를 만들어(`foe.mjs`, 블록매칭 + 최소제곱) 실측한 결과:

| 지점 | 실제 진행 방향(FOE) | v1 화살표가 가리킨 곳 | 판정 |
|------|------|------|------|
| A 0:06 상가거리 | **x=887** | x=1265 | 🔴 **378px 반대쪽** — 화면 절반을 가로질러 틀림 |
| A 0:12 상가거리 | x=741 (계속 왼쪽으로) | — | 길은 **왼쪽으로 휜다**. v1은 오른쪽으로 그렸다 |
| C 0:26 용문교 | x=1031 | x=988 → 꺾어서 1215 | ⚠ 직진부는 맞고 **우회전 폭이 과장됨** |
| C 0:32 다리 끝 | x=1090 | — | 실제 드리프트는 +59px뿐 (v1은 +227px로 꺾음) |
| A 2:58 108계단 | (969, 540) | (1030, 705) | ⚠ x는 근사, **끝점이 165px 너무 낮음** |

**결론: 화살표는 사람이 찍는 게 아니라 뒤따르는 영상에서 유도해야 한다.**

### 1-2 🔴 타임라인이 12곳에서 튄다 = "툭 끊김"

스펙을 기계로 검사한 결과, 같은 클립 안에서 시간이 건너뛰거나 되감기는 지점이 **12곳**:

```
02→03  4초 건너뜀      15→16  8초 건너뜀       30→31  3초 되감김
03→04  3초 건너뜀      17→18  25초 건너뜀 🔴   31→32  3초 건너뜀
11→12  2초 건너뜀      18→19  1초 건너뜀       34→35  2초 되감김
24→25  1초 · 27→28  3초 · 29→30  1초
```

여기에 **클립 이음매 3곳(A→B, B→C, C→A)은 전환 효과가 아예 없다.**
정지 프레임 다음에 다른 시각의 영상이 붙으면 눈이 바로 알아챈다.

### 1-3 빨리감기가 후반부에 애매해지는 이유
전 구간 **고정 배속**이었다. 6배속이 83초를 14초로 누르는 건 좋지만,
같은 6배속이 20초 구간에 걸리면 "왜 지금 빨라지지?"가 된다.
또 **정지 화살표 다음 클립이 다른 시각에서 시작**하니(§1-2) 화살표가 가리킨 방향으로
빨리감기가 이어지지 않았다. 사용자 지적 그대로다.

### 1-4 클로즈업 프레이밍이 어긋난 이유
`crop`의 `cx/cy`를 **"이 점을 중심에 놓는다"가 아니라 "남는 여백의 몇 %"**로 구현했다.
직관과 반대라 값을 넣을 때마다 빗나갔다(大雄寶殿 현판은 3번 만에 맞았다).

### 1-5 폴라로이드에 퇴장이 없다
찰칵 → 등장 → 유지까지만 있고 **옆으로 빠지는 동작이 없다.**
ffmpeg 필터로 카드를 움직이는 게 번거로워 정적으로 둔 것 — 설계 태만이다.

## §3 v2 설계

### 3-1 포맷 — 세로 밴드 (기본값)
```
1080 × 1920
  ├ 배경  : 같은 프레임을 확대·강블러·암전해서 꽉 채움 (죽은 여백 없애기)
  ├ y 0~656   : 케이커 · 포인트 칩 · 제목(한글) · 부제(영문)
  ├ y 656~1264: 16:9 실사 밴드 (1080×608) — 화살표·폴라로이드는 이 안에서만
  └ y 1264~1920: 로케일 해설 캡션 · 워터마크
```
가로 16:9 마스터도 같은 비트 스펙에서 뽑는다(`format: "wide"`).
⚠ 밴드가 작아지므로 **화살표 굵기·셰브런을 1.6배로 재보정**해야 한다.

### 3-2 화살표 — FOE에서 유도 (핵심)
1. 정지 시각 T에서 **T+0.8 / +1.6 / +2.4 / +3.2초** 헤딩을 측정
2. `pan` 점수가 높으면 = 걷는 게 아니라 고개만 돌린 것 → **화살표를 그리지 않는다**
3. 헤딩 x가 창 전체에서 **폭의 8% 미만** 이동 → `직진`(코너 없음)
4. 8% 이상 이동 → 드리프트가 시작된 시점 비율에 **날카로운 코너 1개**, 방향은 드리프트 부호
5. 경로 끝점 = `(heading_x, 지평선과 밴드 바닥 사이 72% 지점)` — **지평선까지 끌지 않는다**(v1 결함)
6. 계단 구간은 기존 `steps` 플레이트 유지(직선 경로 + 원근 압축)

→ 사람이 좌표를 찍는 일이 사라진다. **감사 가능**하고, 다른 관광지에 그대로 돈다.

### 3-3 전환 — 끊김을 문법으로 막는다
| 상황 | 처리 |
|------|------|
| 정지 → 같은 시각에서 이어지는 클립 | 하드컷 (같은 프레임이라 안 보임) + 화살표 0.4초 페이드아웃 |
| 같은 클립 안 시간 점프 | 0.45초 디졸브 |
| 클립 A→B→C 이음매 | 0.8초 디졸브 + 위치 카드(다음 구간 이름) |
| 배속 구간 진입/이탈 | 속도 램프(§3-4)가 전환을 겸한다 |

🔴 **상설 게이트:** 빌드 전에 스펙을 검사해 **미처리 점프가 하나라도 있으면 실패**시킨다.
v1의 12곳은 이 게이트가 없어서 나갔다.

### 3-4 속도 램프
고정 배속 폐지. `setpts` 시변식으로 **1x →(0.6초)→ N x → (0.6초)→ 1x**.
배속 구간 **출력 길이 상한 10초**. 넘으면 구간을 쪼개고 사이에 실속 컷을 끼운다.
그리고 **배속 구간의 첫 프레임 = 직전 화살표 정지 프레임**을 강제 → 화살표가 가리킨 방향으로 화면이 달린다.

### 3-5 폴라로이드 — 4박자
```
찰칵(0.14초 화이트 블룸) → 인화지 등장(0.92→1.02→1.00 오버슈트, 0.5초)
→ 유지 2.2초 → 옆으로 빠짐(가로 이동 + 6° 회전 + 페이드, 0.6초)
```
HTML/WAAPI로 옮기면 전부 CSS 몇 줄이다. ffmpeg으로 우겨넣던 걸 그만둔다.

### 3-6 클로즈업 — 좌표계를 바꾼다
`cx/cy`(여백 비율) 폐지 → **`focus: [x, y, w, h]` 원본 픽셀 사각형**.
렌더러가 전체 프레임 → 그 사각형으로 ease-in-out 크롭한다.
빌드 시 **마지막 프레임을 자동으로 덤프**해서 눈으로 확인 가능하게 한다.

### 3-7 그레이딩 · 필터
1. **렌즈 왜곡 보정** — `lenscorrection` (광각 배럴, 난간·수평선이 휘어 있다)
2. **본 그레이드** — S커브 강화 + 스플릿 톤(그림자 청록 / 하이라이트 웜)
3. **할레이션** — 하이라이트만 뽑아 블러 후 스크린 합성 (여름 햇빛에 공기감)
4. **미세 그레인** — 디지털 느낌 제거
5. **LUT 슬롯** — `.cube` 파일을 스펙에서 갈아끼울 수 있게
6. 비네트는 v1보다 **약하게** (코너가 무거웠다)

### 3-8 타이포 · 타이틀

🔴 **영상에 박히는 글자는 전부 영어다 (사용자 확정 2026-07-29).**
손님이 100% 외국인이므로 **한국어는 마스터가 아니라 10로케일 변형 중 하나**다.
제목·부제·워터마크·자막 전부 영어 기준으로 쓰고, 나머지 9개 로케일은 거기서 번역한다.
POI 고유명사는 로마자 표기 + 필요하면 짧은 설명을 붙인다
(예: `Yongmun Bridge` / `Daeungbojeon Hall` / `Haesu Gwaneum — Goddess of Mercy`).

- 오프닝 타이틀 카드(POI 이름 + 총 소요 + 포인트 수)
- 비트마다 **포인트 칩 `POINT n / N`** — 지금 어디쯤인지 알려준다
- 밴드 위: 한글 제목 + 영문 부제 / 밴드 아래: 해당 스팟 해설 1~2줄
- 엔딩 카드(다음 안내 · 앱 CTA)
- **10로케일은 텍스트 교체만** — HTML 오버레이라 폰트·레이아웃이 자동으로 따라온다.
  원고는 `match_pois.content_locales`의 `haedong_yonggungsa`(10로케일 완비) 재사용.

## §4 아키텍처 변경

**오버레이 레이어를 sharp/SVG에서 HTML→알파 PNG로 이관한다.**

```
docs/video-specs/<slug>.json        비트 스펙 (+ focus 사각형, 전환, 램프)
scripts/video-guide/
  heading.mjs      ← 신규: FOE 측정 (foe.mjs 승격)
  authorArrows.mjs ← 신규: 헤딩 → 화살표 경로 자동 생성
  validate.mjs     ← 신규: 연속성 게이트
  scene/…          ← 신규: 비트별 오버레이 HTML 생성 (브랜드 셸 상속)
  lib/geometry.mjs   기존 유지 — SVG path d 문자열을 HTML로 내보냄
  build.mjs          오케스트레이터 (밴드 합성 · 램프 · 전환 · 그레이드)
scripts/render-howto-video.mjs      기존 렌더러 재사용 (--alpha)
```

⚠ **렌더러가 `playwright`를 필요로 하는데 이 워크트리엔 `node_modules`가 없다.**
`sharp`처럼 `createRequire`로 우회할 수 없다(브라우저 바이너리 경로까지 얽힘).
→ **결정 필요:** 이 워크트리에 `npm ci`를 돌릴지, 아니면 `atockorea-video` 워크트리에서 렌더할지.
