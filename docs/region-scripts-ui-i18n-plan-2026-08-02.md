## §2 계승할 재질 — 지어내지 말 것

문+시트 패턴은 **이미 앱에 있다**: `components/tour-mode/AppManual.tsx` `variant='button'`.

```
tr-home-card tr-press  min-h-[56px] w-full  px-4 py-3
  ├ span.tr-chip.tr-chip--accent  h-9 w-9   ← 아이콘
  ├ h3.tr-card-text.font-bold
  └ IconChevronRight  text-[--tr-ink-3]
```

🔴 **액센트는 아이콘 칩에만.** 슬래브 전체를 액센트로 덮은 판본이 있었고 되돌렸다
(AppManual 주석, 2026-07-28): *"가장 안 급한 것이 가장 큰 것이 됐다. 강조는 예산이고,
오늘 어디 있는지 알려주는 카드가 1순위다."* 일정 탭의 주인공은 오늘 일정이다.

시트는 `components/tour-mode/Sheet.tsx`가 스크롤·포커스·Escape·스프링을 이미 갖는다.

번역 방식의 정본은 `scripts/translate-poi-locales.ts`다. 재사용 목록이 그 파일 머리에
적혀 있다 — `i18n-work/RULES.md` + `styleguide/<locale>.md`(**요약 금지, 전문 로드**),
`glossary/<locale>.json`(고유명사 **축자**), `verifyUnit` G1~G11(실패 시 findings 되먹여
1회 재시도, 그래도 실패면 건너뜀 — *"틀린 번역보다 번역 없음이 낫다"*). **`chatCompletion`

### U2 · 리스트 시트 + 하니스 교체 (같은 커밋)

`Sheet` 안 세로 리스트. 행 = **좌측 64×64 슬롯 + 제목 + 티저 2줄 + chevron**.
슬롯이 고정 크기라 사진(3편)과 이모지(13편)가 섞여도 줄이 어긋나지 않는다 — 사진을

리스트 → 전문은 **같은 시트 안 push/pop**(`view: 'list' | 'detail'`). 시트 2단은 iOS
뒤로가기가 꼬인다.

⚠ **B1 — 스크롤·포커스는 따라오지 않는다.** `Sheet`는 열릴 때 한 번만 포커스를 준다.
같은 컨테이너를 재사용하므로 전환 시 **`scrollTop = 0` + 제목으로 포커스 이동**을 직접

🔴 **하니스는 이 커밋에서 같이 고친다.** 현재 `scripts/shot-region-scripts.mjs`는 일정

없어져 **exit 2로 죽는다**(오늘 그렇게 만들었다). 선택자 교체가 U5로 밀리면 안 된다.

### U3 · 강조 — 파서 · 게이트 · 마크업

tour-mode에 마크다운 렌더러가 없다(확인함). 최소 인라인 파서를 만든다.

| | 지금 | 바꿀 것 |
|---|---|---|
| 본문 기본 | `--tr-ink` | **`--tr-ink-2`** |
| 강조 | 없음 | `**…**` → `--tr-ink` + semibold |

색과 굵기 **두 축**. 🔴 **액센트색은 본문에 쓰지 않는다** — `--tr-accent-deep`은 링크·칩이
이미 쓰고 있어서 "누를 수 있는 것"과 섞인다. 프리미엄은 색을 더 쓰는 게 아니라 위계를
만드는 것이다. 밀도는 **문단당 1~2곳**.

⚠ **B3 — 잉크 강등은 스킨 게이트를 통과해야 한다.** 기본 라이트에서 `#565d66` on
`#fcfcfb`는 **계산상 6.5:1**로 AA를 넘지만 이건 한 스킨의 계산이지 측정이 아니다.
스킨은 10종 × 라이트/다크다. 떨어지면 본문은 `--tr-ink` 유지 + 굵기 한 축만.

⚠ **B2 — `**`가 새는 곳.** 라우트는 `body`를 원문 그대로 준다. 파서를 전문에만 붙이면
**리스트 티저에 별표가 보인다.** → 강조는 **`body`에만**, `title·teaser·fun_fact` 금지.
파서가 유일한 렌더러다.

🔴 **`checkMarkup`은 `**`를 모른다.** 실제 구현은 HTML 태그 멀티셋과 마크다운 **링크
개수**만 본다. 게이트를 **새로 써야 한다**(쌍 개수 비교). 안 쓰면 번역이 강조를 흘려도
아무도 모른다.

강조 파서는 순수 함수 → **jest 케이스 필수**(정본 게이트가 `tsc && jest`다).
`<strong>` 인라인 삽입이 `keep-all` 상속에서 어떻게 접히는지는 소스로 알 수 없다 →
`scripts/qa-cjk-render.mjs`로 실측.

### U4 · 지도 알약 + 장소 행

- 알약: `tr-label`(12px)·`px-3 py-1.5` → **`tr-meta`(11px)·`px-2.5 py-1`** + 작은 지도 아이콘
- 🔴 **탭 타깃 44px 불가침.** 알약은 11px×1.3 + py-1 ≈ **22px**이므로 히트 영역은
  `after:absolute after:-inset-[11px]`로 정확히 채운다. (`-inset-2`면 38px — 6px 모자란다)
- 🔴 **전화번호 링크에도 탭 타깃 규정이 없다.** 같은 행의 두 번째 탭 타깃이다. 같이 고친다.
- 거리 줄이 전화번호 아래에서 들여쓰기되는 현상(관측만, 원인 미규명) → 이때 실측해서
  정리. 전화·거리를 세로 2줄로 내리는 쪽이 안전할 수 있다.

`npm run gate` · 스킨 대비 게이트 · `qa-cjk-render.mjs` · 스크린샷 컷 3종 추가

## §4 번역

### T0 · 원문 동결

🔴 **출처 0건 4편을 먼저 보강한다** — samda-sammu · seolmundae · ponies · weather-wind.
이 중 3편은 본문에 숫자가 있다(1만 8천 신·오름 360개 / 1276년·1986년·천연기념물 347호 /
1,947m). 지금 번역하면 **검증 안 된 숫자가 8배로 복제된다.**

그 다음 U3의 `**` 마크업을 얹은 en·ko 32행이 번역 소스가 된다. **합격한 문장은 한 글자도
바꾸지 않는다** — 마크업만 얹는다.

### T1 · 자산

`i18n-work/styleguide/`와 `glossary/`에는 **de·fr·it·ru 4개뿐**이다. ja·es·zh·zh-TW는
이 파이프라인보다 먼저 있던 로케일이라 자산이 없다 → **해당 언어 배치 전에 스타일가이드를
먼저 쓴다.**

### T2 · 순서

**`zh · zh-TW` → `de · fr · it · ru` → `ja · es`**

근거는 자산이 아니라 **검수 가능성**이다. 사장님이 읽을 수 있는 언어는 중·영·한뿐이므로,
**zh를 먼저 넣어야 제 번역 품질의 표본을 사람이 한 번은 확인**할 수 있다. 그게 통과해야
나머지 6개를 기계 게이트만 믿고 보낼 근거가 생긴다.

### T3 · 배치 — 언어당 원자적

🔴 **D7(즉시 라이브)의 직접적 결과다.** 배치 도중 5편만 들어가면 손님 화면에 **독일어 5장 +
영어 11장**이 섞인다(라우트가 주제별로 en 폴백). **한 언어 = 한 트랜잭션.** 실패하면 통째로
롤백해 반쯤 번역된 상태를 라이브에 남기지 않는다.

### T4 · 적용

`(script_id, locale)` **upsert**, 다른 로케일 행 불가침.

> "INSERT only"는 과교정이다. 2026-07 유료번역 70건 소실은 **jsonb 한 덩어리의
> read-modify-write**였고, 여기는 로케일이 행으로 쪼개져 있어 그 형태가 **구조적으로
> 불가능**하다. INSERT만 허용하면 오타를 영영 못 고친다.

### T5 · 게이트

`lib/i18n/pipeline/gates.ts` `verifyUnit`. **D7로 승인 게이트가 사라졌으므로 이게 6개 언어의
유일한 방어선이다.**

| 게이트 | 잡는 것 | 상태 |
|---|---|---|
| `checkNumbers` | **이 원고는 숫자가 생명** — 2,371 · 1,947.06m · 22,108km · 14,442 | ✅ 천단위 구분기호·선행 0·로마숫자·연대 축약까지 이미 처리 |
| `checkLengthRatio` | 독일어 팽창 / 중국어 수축 | ✅ 언어별 상하한 있음 |
| `checkUntranslated` · `checkCharset` | 영어 잔존 · 키릴/간번체 혼입 | ✅ |
| `checkMarkup` | `**` 강조 유실 | 🔴 **`**`를 모른다 — 신규 작성 필요** |
| `checkGlossaryTokens` | 음차 일관성(haenyeo·oreum) | 🔴 **`/⟦G\d+⟧/`는 자리표시자 봉인을 센다. 손 번역에는 봉인이 없어 0개 vs 0개로 항상 통과 — 지금 쓰면 "게이트가 0개 재며 초록"** |
