## 1. 홈 「더 보기」 — 접힘이 아니라 **엿보기(peek)**

> "챗 탭 밑에 how this app works 탭만 넣고, 더 보기에서 세 개만 펼치고,
> 나머지 앱들이 있다는 느낌으로 **희미하게 세 개 아이콘 머리가 보이게** 접고,
> 거기에 더 보기 버튼을 넣고 누르면 펼쳐지도록"

**I6 답:** 완전 접힘(현재 구현) ❌ / 완전 펼침 ❌ / **엿보기 ✅**

첫 화면 구성:

```
[ 지금 카드 ]
[ 칩 (상태 파생, 최대 2) ]
[ 채팅 미리보기 ]
[ 앱 사용설명서 ]          ← 채팅 바로 밑 고정 (지금은 더 보기 안에 있다)
[ 타일 3개 ]               ← 펼쳐진 채로
[ 다음 줄 아이콘 머리만 희미하게 ]  ← "더 있다"는 신호
[ ⌄ 더 보기 ]              ← 누르면 전량
```

**왜 엿보기인가:** 완전히 접으면 손님이 "없다"고 읽고, 완전히 펼치면 I2가 되돌아간다.
잘린 아이콘 머리는 **"더 있다"를 글자 없이 말하는** 유일한 방법이다.

**신규 티켓 `I7`.** 규칙:
- 위 세 타일이 무엇인지는 **상태에 따라 다르다** — 지금 카드와 같은 리졸버에서 파생하되,
  탭바에 있는 것(채팅·오늘·지도)은 여전히 **제외**(U-D24 유지)
- 엿보기 행은 **`aria-hidden`이 아니다** — 스크린리더에는 "더 보기" 버튼 하나로 들려야 한다
- U-D25 불변: 펼치면 **전량**. `toBeVisible()` 잠금 유지

## 2. OTA 연장 기능 — **계속 쓰게 두고 문구 추가** (L3 확정)

> "계속쓰게, 문구추가"

전세 상품 5종 × 6로케일에 "투어 중 옵션·연장은 당일 가이드에게 현금" 한 줄이 자동 삽입된다.

**남은 것 = `L2`:** 확정 메일·바우처에도 같은 문장. **손님은 예약 후 리스팅을 다시 안 읽는다.**

## 3. 🔴 대화 데이터 수집 — **운영 해자** (X16 확정, 방향이 바뀜)

> "손님을 아는 척할 필요는 없지만, 했던 대화 손님 질문 가이드 답변 등은 수집해서 저장하도록.
> 나중에 이게 남들이 못 따라올 운영데이터 해자"

**두 가지를 분리한다 — 이게 이 결정의 핵심이다:**

| | 결정 |
|---|---|
| **개인화**(두 번째 투어에서 아는 척) | ❌ **안 한다.** 손님은 매번 초면으로 대한다 |
| **집합 데이터**(무엇을 묻고 무엇이 통했나) | ✅ **모은다.** 이게 자산이다 |

**왜 이 분리가 옳은가:** 개인화는 손님이 놀라는 기능이고 프라이버시 부담을 지지만,
**"손님들이 제주 동부에서 화장실을 제일 많이 묻는다"**는 사실은 놀랄 사람이 없고
경쟁사가 살 수 없다. 해자는 후자다.

**신규 티켓 `X20` — 대화 코퍼스.** 설계 제약:
- **`needs` 30일 퍼지(P-D11)는 유지한다.** 그건 개인 정보고, 이 결정이 뒤집는 대상이 아니다
- 모으는 것은 **질문·답변 쌍과 그 맥락**(스팟·시각·투어 유형·언어), **누가 물었는지가 아니라**
- 즉 저장 시점에 **참가자 식별자를 떼고** 넣는다. 나중에 떼는 게 아니라 처음부터
- 기존 `rag:harvest` 플라이휠이 이미 컨시어지 Q&A를 수확한다 — **두 벌 만들지 말 것.**
  가이드 답변·손님 질문으로 **범위를 넓히는 것**이 이 티켓이다
- ⚠ 개인정보 처리방침 문구 확인 필요(사람 게이트)

## 4. 부하 테스트 — **20방 × 전 기능** (K4 확정, 범위가 바뀜)

> "20개방만(프라이빗, 조인투어 골고루), 테스트에 챗뿐 아니라 모든 기능들 하나씩
> 무작위로 테스트해서 테스트가 전 기능 다 커버하도록"

**100방 ❌ → 20방 ✅**, 그리고 **채팅 부하 테스트 → 전 기능 커버리지 주행**으로 성격이 바뀐다.

**신규 티켓 `K4v2`.** 설계:
- 20방: 프라이빗/조인 **골고루**(비율은 라이브 예약 분포를 따른다)
- 각 방이 **서로 다른 기능**을 무작위로 실행 — 채팅·시그널·도착·자유시간·연장·원장·
  좌석·플래너·비전·푸시·SOS. 20방이 끝나면 **전 기능이 최소 1회** 지나가야 한다
- 🔴 **커버리지를 출력한다** — "무엇을 안 돌렸나"를 말하지 않는 주행은 초록으로 오독된다
- 비용 방어: 번역 캐시가 먹도록 **반복 문장**, `sim_tag` 격리, `--cleanup` 필수
- **실 LLM 비용은 여전히 발생한다** — 비전 20회 + 컨시어지 몇 회. 실행 전 한 번 더 확인

## 5. 채팅 하단 두 줄 — **유지** (U-D20v2 확정)

> "두 줄 유지"

시그널 줄과 퀵리플 줄은 **탭 한 번의 결과가 다르다**(시그널은 관제에 알림, 퀵리플은 메시지).
합치면 그 차이가 가려진다. **현재 구현 그대로.**

단, §N-g의 관찰은 남아 있다 — 두 줄의 **재질이 서로 다르다**(하나는 채움, 하나는 테두리).
같은 가족으로 보이게 다듬는 것은 **`N4`에 포함**한다.

> "맞아"
