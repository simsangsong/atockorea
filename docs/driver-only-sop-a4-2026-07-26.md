# 기사 단독 투어 SOP (A4 1장 — 인쇄용)

> 대상: 스마트 가이드 앱으로 손님을 안내하는 기사 (가이드 미탑승).
> 원칙: **말이 안 통해도 앱이 통역한다. 기사는 안전 운행 + 탭 4개만 책임진다.**

---

## 0. 출차 전 (전날 밤 + 당일 아침)

- [ ] 폰 충전 100% + **차량용 충전 케이블** + 거치대
- [ ] 기사 링크 접속 → **차량번호 뒤 4자리** 입력 → 콕핏 입장 확인
- [ ] 콕핏에서 오늘 일정(픽업 시각·장소·손님 수) 확인
- [ ] 데이터 잔량 확인 (스트리밍 아님, 하루 1GB면 충분)
- [ ] 종이 백업 카드 인원수만큼 인쇄해서 차에 비치

## 1. 픽업 (제일 중요한 3분)

1. 손님 확인 후 인사 — 아래 세 문장이면 충분:
   - **"Hello! Welcome!"** (헬로! 웰컴!)
   - **"Please scan this QR."** (플리즈 스캔 디스 큐알) — 종이 카드를 보여준다
   - **"You can talk to me here, any language."** (유 캔 톡 투 미 히어, 애니 랭귀지) — 폰 채팅 화면을 가리킨다
2. 손님 전원이 앱 화면(투어룸)을 연 것을 눈으로 확인
3. 콕핏에서 **[운행 시작]** 탭 ← ★ 이걸 눌러야 손님 메시지가 한국어 음성으로 나온다
4. 출발 전 시그널 **[차량 출발]** 탭 (있는 경우) 또는 첫 메시지 녹음: "출발합니다, 첫 목적지는 ○○입니다"

## 2. 이동 중

- 손님이 뭐라고 보내면 → **한국어 음성으로 자동 재생**된다. 운전 중이면 듣기만.
- 답할 때: 정차 후 **[녹음] 버튼 원탭 → 한국어로 말하기 → 자동 전송** (3초 안에 취소 가능)
  - 손님 화면에는 손님 언어로 번역된 말풍선이 뜬다
- 지연/막힘 → 시그널 **[지연]** 원탭 (ETA 자동 안내)
- ⚠ **주행 중 화면 조작 금지.** 급한 건 갓길 정차 후.

## 3. 스팟 도착 (스팟마다 반복)

1. 주차 후 콕핏에서 해당 스팟 **[도착]** 탭 → 손님 폰에 그 스팟 안내 카드(손님 언어)가 자동 발사된다
2. 주차 위치가 애매하면 **[주차핀]** 탭 (내 위치가 손님 지도에 핀으로 뜸)
3. 자유시간 주기: **[복귀시간]** 탭 → +30/45/60/90분 선택 → 손님 폰에 카운트다운
4. 손님이 늦으면 앱이 알아서 다시 알림 → 그래도 안 오면 콕핏에 "일행 대기" 경고 + 전화 버튼
5. 화장실/맛집 질문은 손님이 채팅에 물으면 앱이 핀 지도로 답한다 — 기사가 안 해도 됨

## 4. 문제 상황

| 상황 | 행동 |
|---|---|
| 차량 고장/사고 | 시그널 **[차량 문제]** 탭 → 운영센터에 자동 알림 → 운영센터 전화 대기 |
| 손님이 SOS를 누름 | 손님에게 다가가 상태 확인 → 운영센터에서 연락 옴. 응급이면 **119 먼저** |
| 손님을 잃어버림 | 채팅으로 위치 공유 요청이 자동으로 감 → 핀 위치로 이동 |
| 앱/폰이 죽음 | 종이 카드의 운영센터 번호로 전화 → 운영센터가 손님과 직접 채팅 |
| 네트워크 음영 (산간) | 미리 녹음: "이 구간은 신호가 약합니다. 20분 뒤 정상화됩니다" |
| 손님 폰 배터리 사망 | 차량용 충전 케이블 제공. 일행 중 1명만 앱 연결돼 있으면 운영 가능 |

## 5. 종료

1. 마지막 드랍 후 콕핏에서 **[운행 종료]**
2. 분실물 확인 — 발견 시 사진 찍어 채팅에 올리기
3. 현금 수취(픽업비/연장 등)가 있었으면 콕핏 정산 기록 확인
