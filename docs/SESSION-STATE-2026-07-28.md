## 2. 방금 끝낸 작업 — 재질 업그레이드 (브랜치 `claude/material-premium`)

**머지 여부 확인 필요.** 푸시는 됐고 PR은 이 기록 시점에 아직 안 냈을 수 있다.

넣은 것:
- **승강(elevation) 체계** `--tr-elev-1/2/3` + `--tr-rim` + `--tr-card-line`
  (라이트/다크 각각). 2겹 그림자 = 접촉 + 주변광.
- `.tr-card` 가 재질을 얻음 — 전엔 `background` + `border-radius` **뿐**이었다.
- `.tr-home-card` 를 같은 토큰으로 통일(재질 언어가 둘이었다).
- `.tr-atmos` — 스킨 위에 얹는 **광원 한 겹**(radial). `--tr-accent-soft` 를 읽어서
  스킨 10종이 자기 색을 유지한 채 하늘만 얻는다. `contrast` 스킨은 제외.
- **N1 완료** — `.tr-chip-tap` (+`--urgent`/`--quiet`). 테두리를 `currentColor` 로.
- `.tr-card-hero` — 홈 상태 카드가 화면의 주인공. **한 화면에 하나만.**
- 앱 설명 버튼: 전폭 액센트 슬래브 → 표면 카드 + 액센트 아이콘 칩.

**실측 결과(4개 스킨×테마 조합):** 시그널 칩 1.04 → **15.78~18.16** · 퀵리플 1.07 → **3.08~4.90**.
전부 기준 3.0 통과. 게이트: tsc 0 · 1217 pass · skinContrast/typeDiscipline/shellStackingContext green.

### ⚠ 이 작업에서 계측기가 세 번 틀렸다 (다음 사람이 같은 함정에)
1. rgba 알파를 버려서 → 없는 글자 대비 결함(2.06)을 만들어냈다.
2. 첫 수정이 수치를 1.04→1.14 밖에 못 올렸는데 **스크린샷은 고쳐 보였다**(그림자가 테두리처럼 읽힘).
3. `color-mix` 결과가 `color(srgb 0.65 …)` 로 나오는데 0~255로 읽어서 **라이트·다크 숫자가 둘 다 가짜**였다.
→ **대비를 잴 땐 알파 합성 + `color(srgb)` 스케일 둘 다 처리해야 한다.**
