## §D 항구 프로필 · 픽업 로지스틱스

**강정 크루즈터미널 (서귀포 민군복합형관광미항) — 잔여 98회, 물량의 63%**
- 2017 개장, 선석 2개(15만GT×2 동시 접안), 수심 16~17m. 메가십 전용 허브.
- 권역 거리: 중문관광단지 15분 · 서귀포 시내 20분 · 천지연/새연교 20분 · 산방산·용머리 30분 · 성산일출봉 70~80분(오전형만 가능).
- **오전형 6h 추천 루트(강정)**: 천제연/중문 → 산방산·용머리해안 → 점심(흑돼지) → 오설록/카멜리아힐 → 복귀.
- **오후형 5.5h(강정)**: 정방폭포·이중섭거리 → 서귀포매일올레시장(간식) → 새연교 선셋 → 복귀.
- ⚠ 민군복합항 = 보안구역. 터미널 게이트 앞 대기 가능 여부·주차·피켓 규정 **실사 1회 필수**(§F-2).

**제주항 크루즈터미널 (제주시) — 잔여 57회, 프리미엄·일본 선사 중심**

- 권역 거리: 동문시장·용두암 10분 · 협재/한림 40분 · 성산일출봉·만장굴 60분.
- **오전형 6~8h(제주항)**: 성산일출봉 → 우도 or 만장굴 → 점심 → 동문시장 → 복귀 (10h+ 체류 프리미엄십은 grand-highlights 컷판).

## §F 실행 플랜 (W1~W4)

- **W1 리스팅 2×2**: (강정/제주항)×(오전/오후) 4종 — Viator·GYG(en)·Klook(zh) 게시. 카피 3요소 고정:
  ① **Back-to-ship 보장** — "출항 90분 전 복귀 설계 + 실시간 복귀 카운트다운 앱"(NoticeBanner 10/5분 경고 = 시스템 증빙)
  ② **항구 게이트 픽업 + 미팅포인트 사진**(정확히만나기 프리셋)
  ③ **차량 무료 WiFi**(에그) + 앱 실시간 통역(가이드 없이 기사 단독 = 가격 경쟁력).
- **W2 항구 실사 1회**(사람): 강정 게이트 대기 규정·주차 확인 + 양 항구 미팅포인트 사진 촬영 → 앱 프리셋 등록.
- **W3 기항일 연동 판매**: 위 §G 달력대로 기항일에만 캘린더 오픈(온디맨드 무한과 충돌 없음 — 크루즈 SKU만 기항일 화이트리스트). 하이밸류 콜(The World 10/13, Silversea 4회, 오버나이트 5회) 지명 타겟.
- **W4 WiFi SOP**: v1=기사 폰 핫스팟(기기 0원), v2=에그 2대/차(1대는 자유시간에 리드 게스트 지참 — 길잃음 신호·복귀 카운트다운이 손님을 따라가야 함). 분실 보증금 규정 1줄.
- **버퍼 불변식**: 복귀 = 출항 90분 전(all-aboard 통상 60분 전 + 30분 여유). 오전 8h 기항 = 실가용 6h, 오후 7.5h 기항 = 5.5h. 코스는 이 안에서만 설계.
